One funny fortune cookie line for an AI agent, in the voice of a fortune slip: your tokens run out exactly when you are about to get the joke.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the fortune to `/output/entry.txt`: UTF-8, 61 characters, byte-identical on every run.
